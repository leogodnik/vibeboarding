# Живой прогон: что проверять

Статическое ревью прошло полностью. Эти семь вещей оно проверить не может — только реальный
запуск плагина в чистой папке. Пока прогон не сделан, плагин не считается готовым к выпуску.

## Как запустить прогон

```bash
rm -rf /tmp/vb-test && mkdir -p /tmp/vb-test
```

Затем в новой сессии Claude Code, запущенной в `/tmp/vb-test`:

```
/plugin marketplace add "/Users/leogodnik/Starter Skill/vibeboarding"
/plugin install vibeboarding@leogodnik-plugins
```

Если в отчёте об установке будет `Run /reload-plugins to activate.` — выполнить `/reload-plugins`.
Потом запустить `/vibeboarding`.

Прогонов нужно два: один в режиме «Быстро» с ответами «только я» и «файл двойным кликом»,
второй в режиме «С объяснениями» с ответами «я и коллеги» и «настоящее приложение».

## Семь наблюдений

1. **Команда вообще появляется?** Набрать `/vibe` и посмотреть автодополнение. Ожидается
   `/vibeboarding`. Если работает только `/vibeboarding:vibeboarding` — поправить оба README.

2. **Сколько раз система спросила разрешение во время генерации?** Правильный ответ — ноль.
   Любой запрос разрешения, показанный человеку, обесценивает всю идею плагина. Смотреть
   особенно на моменты: `node --version`, `npm install`, открытие HTML в браузере, `git init`.

3. **Успевают ли записанные права подействовать?** Файл `.claude/settings.local.json`
   пишется на первом шаге генерации. Проверить, что `git init` и `git commit` через
   несколько минут в той же сессии проходят молча.

4. **Запустить в непустой папке и в домашней папке.** Убедиться, что ничего не записано за
   пределами созданной подпапки проекта и что `~/.claude` не тронут. Это самый опасный
   сценарий: до правки скилл мог записать разрешения в глобальные настройки.

5. **Не смешались ли свободный текст и виджет выбора?** Пройти все семь ходов плюс
   подшаг про файл на шаге 4 и убедиться, что ни в одном сообщении не было вопроса,
   ответ на который потерялся.

6. **Прогон «настоящего приложения»: совпадают ли имена?** Команда в `package.json`,
   раздел «Как запустить» в `CLAUDE.md` и шпаргалка должны говорить одно и то же слово
   в слово. Документирована должна быть ровно одна команда — `npm start`.

7. **Перечитать всю переписку глазами человека без бэкграунда.** Искать слова
   «репозиторий», «зависимости», «деплой», «авторизация», «фронтенд», «бэкенд», любые
   английские сообщения об ошибках и коды возврата. Ничего этого быть не должно.
