# Как установить VIBEBOARDING

Инструкция для тех, кто раньше не работал с терминалом. Всё, что нужно набрать, можно
скопировать мышкой и вставить.

Установка делается **один раз**. Дальше плагин просто есть.

---

## Что нужно до начала

**Claude Code.** Это программа от Anthropic, в которой всё и происходит. Если её ещё нет —
поставьте по инструкции с [code.claude.com](https://code.claude.com/docs), там же описан вход
в аккаунт. Нужен активный тариф Claude — Pro, Max, Team или Enterprise.

**Терминал.** Это окно, в котором вы пишете команды текстом.

- **На Mac:** нажмите `Cmd + пробел`, наберите «Терминал», Enter.
- **На Windows:** нажмите «Пуск», наберите «Terminal», Enter.

Если вы видите окно с текстом и мигающим курсором — вы на месте.

---

## Шаг 1. Запустите Claude Code

В терминале наберите одно слово и нажмите Enter:

```
claude
```

Появится окно Claude Code — с рамкой, приветствием и строкой ввода, которая начинается со
значка `❯`.

**Как понять, что вы внутри Claude Code, а не в обычном терминале:** строка ввода начинается
с `❯`, а внизу видна полоса состояния. Если перед вами строка вида
`имя@MacBook-Air ~ %` — вы ещё в терминале, и команды со слэшем работать не будут.

---

## Шаг 2. Подключите каталог плагинов

Скопируйте эту строку целиком, вставьте в Claude Code и нажмите Enter:

```
/plugin marketplace add leogodnik/vibeboarding
```

В ответ появится: `✔ Added marketplace: leogodnik`

Если вместо этого открылось окно с полем для ввода — вставьте туда `leogodnik/vibeboarding`
и нажмите **Enter**. Только Enter: клавиша Esc отменит ввод, и ничего не установится.

---

## Шаг 3. Установите плагин

Следующая строка:

```
/plugin install vibeboarding@leogodnik
```

Откроется карточка плагина с описанием. Подтвердите установку — область можно оставить ту,
что предложена.

Если в ответе будет `Run /reload-plugins to activate.` — наберите:

```
/reload-plugins
```

---

## Шаг 4. Проверьте, что всё встало

Начните набирать в Claude Code:

```
/vibe
```

Под строкой ввода должна появиться подсказка `/vibeboarding:start`. Значит, готово.

---

## Как пользоваться

**Создайте пустую папку для будущего проекта.** Это важно: плагин строит проект с нуля.

На Mac — в Finder, на Windows — в Проводнике. Назовите её как угодно, например `Мои расходы`.
Лучше положить её туда, где вы легко её найдёте: на рабочий стол или в документы.

**Откройте эту папку в терминале.** Самый простой способ на Mac: нажмите на папку правой
кнопкой → «Новый терминал в папке». Если такого пункта нет, наберите в терминале `cd `
(со пробелом в конце) и перетащите папку мышкой прямо в окно терминала — путь подставится сам.
Нажмите Enter.

**Запустите Claude Code и плагин:**

```
claude
```

```
/vibeboarding:start
```

Дальше просто отвечайте на вопросы. Их восемь, все на русском, ни на один не обязательно
знать технический ответ — у каждого есть вариант «не знаю, решите сами».

Перед тем как что-то создавать, Клод покажет, что понял, и дождётся вашего «да».

---

## Если что-то пошло не так

**`zsh: no such file or directory: /plugin`** — команда набрана в обычном терминале.
Сначала наберите `claude`, дождитесь окна Claude Code, и только потом команду со слэшем.

**`/plugin isn't available in this environment`** — вы в расширении для редактора кода,
а не в терминальной версии. Откройте обычный терминал и наберите `claude`.

**Команда `/vibe` ничего не подсказывает** — повторите шаг 3, а затем наберите
`/reload-plugins`.

**Всё остальное** — просто опишите проблему Клоду своими словами прямо в чате. Он для этого
и нужен.

---

## Как обновить плагин потом

Когда выйдет новая версия, в Claude Code наберите:

```
/plugin marketplace update leogodnik
```
